# UnitedMC — Security Policy

**Last Updated:** October 5, 2026

UnitedMC takes the security and stability of its Minecraft server, Discord community, plugins, and related services seriously.

## Reporting a Security Issue

If you discover a potential security vulnerability affecting UnitedMC, please report it privately through the official UnitedMC Discord server:

**Discord:** https://dsc.gg/unitedmc

Please avoid publicly posting details of an undisclosed vulnerability, especially information that could allow others to exploit it.

When reporting an issue, please provide:

- A clear description of the issue.
- The affected feature or service.
- Steps to reproduce the issue, where safe to do so.
- Any relevant screenshots, logs, or other evidence.
- Information about the potential impact.

## What to Avoid

Please do not:

- Intentionally damage or disrupt UnitedMC services.
- Attempt to obtain another person's private information.
- Exploit a vulnerability against other players.
- Perform actions that could crash or significantly degrade the server.
- Publicly disclose a vulnerability before the UnitedMC team has had a reasonable opportunity to investigate it.

## Security Updates

UnitedMC may investigate reported issues and deploy fixes or other mitigations when appropriate.

We appreciate responsible reports that help keep UnitedMC safe and stable for everyone.
